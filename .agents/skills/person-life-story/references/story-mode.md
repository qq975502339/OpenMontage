# 大头剪贴故事视觉模式

大头剪贴是人物一生的叙事主线，依时间与故事脉络呈现早年、重要经历、转折和结局。主持人负责开场与收尾；在适合人物亲自表达的关键时刻插入一次或多次第一人称人物片段，片段紧扣该阶段人物的事件、处境和情绪，结束后回到剪贴主线继续。采用 9:16 竖屏画幅。

本模式完整保留原项目的大头真人照片剪纸、小舞台、实物道具、字体、颜色、场景动作、镜头和转场，不要改成个人扁平卡片或默认黑底。优先阅读本技能内 `vendor/bighead-collage/SKILL.md` 和其 `style-card.md`、`references/mapping.md`、`references/engine.md`、`references/production.md` 与 `references/taste.md`；流程、例子、脚本、字体及参考图均随技能提供。原项目采用 MIT，字体另有 OFL，参考图、素材的权利按原项目 README 与各自来源处理。

## 使用

1. 先依原技能核实真实人物、公司、事件及素材授权，编写口播、导演表、场景调度和动作表；人物照片、图标及道具按具体语义选择，不能把虚构素材当作真实事件证据。确认配音和素材来源、可用依赖后运行原项目检查与配置。有关模型、API 和费用，按当次实际环境与用户已有授权选择，缺少必要条件时说明。
2. 在技能目录运行 `node scripts/create-story.mjs <新工程目录>`。它使用本技能 `vendor/bighead-collage/scripts/new_film.py` 创建原样竖屏工程。不会覆盖已有目录，也不自动安装依赖。可选环境变量 `BIGHEAD_SKILL_PATH` 指向另一个完整的原版技能目录。
3. 按 [Token Plan 图片与配音](token-plan-media.md) 生成主线旁白（默认 `longanlingxin`），再作为正式录音导入并按原项目流程制作字级时间线；用户指定其他配音或提供录音时按用户要求执行，子项目默认配音与本技能冲突时以本技能为准，编写导演表，准备并核对人物照片、场景、道具，使用 `stage.js`、`acts.js` 与原版视觉制作场景，再进行音效、音乐、字幕、抽帧和成片校验。具体命令见原项目 `SKILL.md` 和 `references/production.md`，运行脚本时以本技能 `vendor/bighead-collage` 为原项目目录。
4. 采用 9:16 竖屏，按故事需要确定时长；根据分镜分别渲染各段，在主线指定位置插入第一人称片段，再与主持人首尾合成。视觉不是每句话配一张静图。

技能中包含原项目代码和参考资料，不代表已安装运行依赖或开通所有模型服务；按实际情况检查。默认配置和提供商选择以原项目真实配置为准，不预设已有授权或已经下载模型。参考故事不等于真实素材授权。

## 竖屏片段合成

分别渲染主持人、各段剪贴及插入的第一人称片段后，可写合成清单（路径相对清单所在目录）：

```json
{"clips":["host-intro.mp4","bighead-early.mp4","selfie-1.mp4","bighead-later.mp4","selfie-2.mp4","bighead-ending.mp4","host-outro.mp4"],"audio":[{"file":"voice.wav","start":0.2,"volume":1},{"file":"music.wav","start":0,"volume":0.08}]}
```

运行 `node scripts/assemble-story.mjs <清单.json> <新文件.mp4>`。该工具按顺序拼接画面并混合列出的音轨；不保留输入片段自带音频，不生成配音、字幕或音效，不自动计算口播对齐。各轨音量和起点要根据片子检查；输出为 720×1280 / 24 fps，画幅不同的片段会等比缩放并补黑边。它只做硬切；需要动画转场时应单独设计和渲染。依赖本机 ffmpeg，不覆盖已有目标文件。检查成片音量、字幕安全区、时间对齐及故事与主持人画面衔接。
