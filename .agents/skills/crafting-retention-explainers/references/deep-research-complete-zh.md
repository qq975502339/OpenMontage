# `deepsearch.txt` 完整中文移植版

本文件完整保留所附 `deepsearch.txt` 的工作流含义，供“高留存深度口播”技能在需要联网研究时使用。

## 调用约定

对**任何**需要网页研究的问题，都应主动使用本模块，而不是只做一次普通网页搜索。它适用于“X 是什么”“解释 X”“比较 X 和 Y”“研究 X”等请求，也应在内容生成前主动启用，只要任务可能需要现实世界信息、案例或当前数据。

## 概览

本模块提供一套系统化的方法，用于进行深入的网页研究。**在开始任何内容生成任务前，先加载并执行本模块**，以确保从多个角度、不同深度和多类来源收集足够信息。

## 何时使用本模块

以下情况都应先使用本模块。

### 研究型问题

- 用户询问“X 是什么”“解释 X”“研究 X”或“调查 X”；
- 用户希望深入理解某个概念、技术或主题；
- 问题需要当前、全面且来自多个来源的信息；
- 单次网页搜索不足以得出可靠答案。

### 内容生成前的预研

- 制作演示文稿或幻灯片；
- 制作前端设计或界面原型；
- 撰写文章、报告或文档；
- 制作视频或其他多媒体内容；
- 任何需要现实案例、当前数据或真实世界信息的内容。

## 核心原则

**不要只凭一般知识生成内容。**输出质量直接取决于事前研究的质量和广度；一次搜索查询永远不够。

## 研究方法

### 阶段一：广泛探索

先用宽泛检索了解全貌。

1. **初步调查**：检索主题本身，了解整体背景；
2. **识别维度**：从初步结果中识别需要继续研究的子主题、议题、角度或方面；
3. **绘制版图**：记录不同观点、利益相关者或立场。

示例：研究“医疗中的人工智能”时，可先检索“医疗人工智能应用”“人工智能医学诊断”“医疗人工智能市场趋势”。由此识别出影像与病理诊断、治疗建议系统、行政自动化、患者监测、监管环境和伦理问题等维度。

### 阶段二：深度挖掘

对每个识别出的重要维度进行定向研究。

1. **具体查询**：为每个子主题使用精确关键词；
2. **多种表述**：尝试不同的关键词组合和说法；
3. **获取全文**：使用环境提供的全文抓取或打开工具（存在 `web_fetch` 时使用它）完整阅读重要来源，而不是只看搜索摘要；
4. **追随引用**：来源提到其他重要资源时，继续搜索那些资源。

示例：在“影像诊断人工智能”维度下，可检索监管批准的系统、胸片人工智能检出准确性、影像人工智能临床试验结果；然后完整阅读关键论文或其摘要、行业报告和真实案例。

### 阶段三：信息多样性与验证

通过主动寻找不同类型的信息，确保覆盖全面。

| 信息类型 | 目的 | 示例检索方向 |
|---|---|---|
| 事实与数据 | 获得具体证据 | 统计、数据、数字、市场规模 |
| 案例与实例 | 理解真实应用 | 案例研究、实例、实施 |
| 专家观点 | 获取权威解释 | 专家分析、访谈、评论 |
| 趋势与预测 | 判断未来方向 | 当年趋势、预测、未来发展 |
| 比较 | 提供背景与替代方案 | 对比、比较、替代方案 |
| 挑战与批评 | 保持平衡 | 挑战、限制、批评 |

### 阶段四：综合检查

在开始内容生成前，逐项确认：

- [ ] 是否已从至少 3—5 个不同角度进行检索？
- [ ] 是否已完整阅读最重要的来源？
- [ ] 是否具备具体数据、案例和专家视角？
- [ ] 是否探索了积极面以及挑战／限制？
- [ ] 信息是否足够新，且来自权威来源？

任何一项为“否”，都应继续研究，再开始内容生成。

## 检索策略提示

### 有效的查询模式

让查询包含具体语境：不要只搜“人工智能趋势”，应加入行业和时间，例如“企业人工智能采用趋势 + 当年”。

在主题后加入权威线索，例如“研究论文”“权威机构报告”“行业分析”。

按内容类型检索，例如“案例研究”“统计数据”“专家访谈”。

始终依据当前上下文中的实际年份加入时间限定，例如“主题 + 当前年份”“主题 + 最新”“主题 + 近期进展”；不得机械沿用过去年份。

### 时间意识

在形成任何查询前，先查看当前日期。根据用户意图使用对应精度：

| 用户意图 | 所需时间精度 | 查询示例 |
|---|---|---|
| 今天、今早、刚发布 | 月、日、年 | `主题 + 完整日期` |
| 本周 | 周期范围 | `主题 + 当周日期范围` |
| 最近、最新、新动态 | 月份 | `主题 + 当月与年份` |
| 今年、趋势 | 年份 | `主题 + 当年` |

用户问“今天”或“刚发布”时，查询必须包含月、日、年；不能只写年份。应尝试数字日期、文字日期和相对时间等不同表述。例如，不能只搜“2026 年科技新闻”，而应同时尝试“2026 年 2 月 28 日科技新闻”和“2 月 28 日今日科技新闻”这类更精确的表述。

### 何时阅读全文

以下情况必须使用可用的全文抓取／打开工具并阅读完整内容：搜索结果高度相关且权威；需要摘要之外的细节；来源包含数据、案例或专家分析；需要理解发现的完整上下文。

### 迭代优化

研究不是一次性动作。每一轮检索后：

1. 回顾已经学到的内容；
2. 找出理解中的缺口；
3. 形成更具体、更有针对性的查询；
4. 重复，直至覆盖充分。

## 质量门槛

研究充分时，应能够有把握地回答：关键事实和数据是什么；2—3 个具体的现实案例是什么；专家如何解释；当前趋势和未来方向是什么；挑战或限制是什么；以及为什么此刻与主题相关。

## 应避免的常见错误

- 一两次搜索就停止；
- 只依赖搜索摘要，不阅读全文；
- 只搜索复杂主题的一个方面；
- 忽视矛盾观点或挑战；
- 已有当前数据时仍使用过时信息；
- 研究完成前就开始生成内容。

## 完成研究后的预期产出

完成研究后，应拥有：

1. 对主题的多角度综合理解；
2. 具体事实、数据点和统计数字；
3. 现实案例与实例；
4. 专家视角和权威来源；
5. 当前趋势及相关背景。

只有做到这些，才能利用收集到的材料进入内容生成，产出高质量且信息充分的作品。
