# 高留存深度口播

目标不是堆砌资料，也不是靠情绪煽动，而是用可核验的反差吸引注意力，再用逐层回答问题留住观众。不要复制参考稿的口头禅、笑点或政治立场，只提炼其叙事方法。

## 固定交付规格：时长与主持人

本技能产出的完整视频一律控制在 **7—8 分钟**。在写口播前，先选定一个可被 5 整除的目标秒数，并把主持人可见出镜精确预算为总时长的 **20%（五分之一）**：

| 成片目标时长 | 主持人累计可见出镜 | 其余画面预算 |
|---|---:|---:|
| 7:00（420 秒） | 84 秒 | 336 秒 |
| 7:30（450 秒，推荐） | 90 秒 | 360 秒 |
| 8:00（480 秒） | 96 秒 | 384 秒 |

“主持人可见出镜”只有全屏中能看见主持人脸部的时间；纯口播但画面切到素材、信息卡或 MG 时不计入。主持人可见出镜占用视频总时长的 20%。主持人用来建立问题、转换视角和回收结论；其余 80% 用证据画面、库存实拍、信息卡与 MG 推进解释。
“主持人可见出镜”的形式只有全屏这一种形式，且每一段主持人出镜的时长不得超过15秒。
## 深度研究：先研究，再写稿

只要任务需要联网研究，或脚本使用现实世界的新闻、政策、数据、人物、公司或案例，在动笔前必须完整阅读并执行[附件 `deepsearch.txt` 的完整中文移植版](references/deep-research-complete-zh.md)。附录是唯一的深度研究流程来源；其中的调用约定、四个研究阶段、检索策略、时间规则、全文阅读、迭代、质量门槛、常见错误与预期产出都必须遵守。

只有附录中的综合检查通过，才能开始下列口播写作。用户要求“不要链接或来源”时，交付稿中可以不列，但研究和核验不能省略。

## 写前四格

在动笔前私下写明：观众原本相信什么、核心问题是什么、可辩护的有限结论是什么、观众看完能获得什么判断。将材料先标为**事实、推断、价值判断**；不要因一句话有冲击力，就把推断写成事实。

## 开场：0—45 秒

使用连续加压的四步：

1. 一个具体异常：数字、后果、场景或身份冲突；
2. 它与常识的反差；
3. 一个明确但尚未回答的问题；
4. 本片会解释什么，以及它和观众有什么关系。

可用句式：

> “看起来是 X，为什么结果却是 Y？关键不只在 X，而在 Z。”

> “这件事影响的不只是 X；真正要问的是，谁承担成本、谁获得收益？”

不要用寒暄、定义或背景资料开场。不要用未经核验的“史上最”“所有人”“一定会”制造钩子。

## 叙事骨架

按主题调整，但优先遵循：

| 段落 | 任务 |
|---|---|
| 钩子 | 提出可信的问题，承诺解释。 |
| 前后变化 | 说明为什么这件事反常。 |
| 规则／机制 | 用最少的必要定义解释系统怎样运转。 |
| 三次揭示 | 每章遵循：问题 → 证据 → 机制 → 现实后果 → 下一个问题。 |
| 摩擦 | 呈现最强的合理反对意见、约束或反例。 |
| 利益与风险 | 分开谈个人、企业、机构和更大系统的影响。 |
| 回收 | 回答开场问题，说明不确定性与后续观察点。 |

每 60—90 秒必须出现一次真实的信息推进：新证据、视角反转、案例、图表比较或一个被回答的问题。最多保留三个未解问题；只有后文确实提供理解工具时才延后回答，不能反复用“后面再说”拖延。

## 口播与画面

按耳朵写：短段落，一口气只讲一个意思，使用具体动词和自然转场。每章结尾给出一句结论，再提出下一问。比喻只能在事实解释清楚后使用。若用户需要画面提示，和口播正文分开写，例如：`[数据卡：同比与绝对值，标注口径和日期]`。

“不是 X，而是 Y”只能在 Y 有证据支持时使用。张力来自清晰的问题和真实的机制，不来自恐吓、阴谋论或给机构强加动机。

## 画面驱动脚本：真实素材、信息卡与 MG

当用户要求真实素材、信息卡或 MG 动画时，交付应是“口播／画面契约”，而非在大纲末尾补一份视觉建议。每个叙事段都写出下列字段。

| 字段 | 要求 |
|---|---|
| 口播 | 一次只推进一个可检验的观点，并标明它是事实、推断或价值判断。 |
| 真实素材 |  分为`证据素材` 与 `库存实拍`。证据素材是能支撑事实的原始网页、表格、现场、采访或录屏。库存实拍来自 Pexels 或 Pixabay，它只负责呈现场景与节奏。 |
| 信息卡 | 只压缩一个结论、数字或对比；关键数字标注口径、日期和定义。 |
| MG | 写明触发语句、画面动作与观众最终应读到的关系，例如“成本项依次进入订单，显示服务链变长”。不要只写“加动效”。 |
| |

## 事实边界

- 每个关键数字都核对日期、范围、分母、定义；不要比较统计口径不同的人群。
- 严格区分收入、利润、现金流、资产、估值和个人财富。
- 预测、学术模型和估算都是条件性情景，不是确定未来，更不能自动证明某个隐藏动机。
- 涉及法律、政治、公司或个人争议，优先核实原始记录，并说明程序状态和不确定性。
- 不要从一个政策结果直接倒推机构动机；只能将其表述为可能的分析。

## 交稿前检查

确认前 45 秒同时有异常、问题和承诺；主要问题都被真正回答；反对意见不是稻草人；结尾回扣开场；脚本让观众获得更清晰的判断，而不是只有更强的情绪。确认总时长落在 420—480 秒、主持人可见出镜恰为总时长 20%，且逐段时长可加总。当交付包含真实素材、信息卡或 MG 时，逐段检查“口播／真实素材／信息卡／MG／素材状态”是否齐全；库存实拍均标明为场景示意，且所有待核实项目均被明确标记。
