# 大头剪贴故事视觉模式

人物经历、创业故事、公司历史等含人物与事件发展、适合故事化表达的内容，主动使用本模式。一个视频只有部分段落讲故事时，可把它作为该段的独立视觉片段；纯数据说明、横屏主持人口播等沿用个人组件，根据内容和用户指定选择。用户明确指定其他视觉风格或画幅时，按用户要求调整。

本模式完整保留原项目的大头真人照片剪纸、小舞台、实物道具、字体、颜色、场景动作、镜头和转场，不要改成个人扁平卡片或默认黑底。优先阅读本技能内 `vendor/bighead-collage/SKILL.md` 和其 `style-card.md`、`references/mapping.md`、`references/engine.md`、`references/production.md` 与 `references/taste.md`；流程、例子、脚本、字体及参考图均随技能提供。原项目采用 MIT，字体另有 OFL，参考图、素材的权利按原项目 README 与各自来源处理。

## 使用

1. 先依原技能核实真实人物、公司、事件及素材授权，编写口播、导演表、场景调度和动作表；人物照片、图标及道具按具体语义选择，不能把虚构素材当作真实事件证据。确认配音和素材来源、可用依赖后运行原项目检查与配置。有关模型、API 和费用，按当次实际环境与用户已有授权选择，缺少必要条件时说明。
2. 在技能目录运行 `node scripts/create-story.mjs <新工程目录>`。它使用本技能 `vendor/bighead-collage/scripts/new_film.py` 创建原样竖屏工程。横屏时使用 `node scripts/create-story.mjs <新工程目录> --landscape`：在工程副本中将舞台设为 1920×1080、脚本画幅设为 16:9，保留原动作和视觉样式；不会覆盖已有目录，也不自动安装依赖。横屏必须重排每个场景、显式调整字幕位置并核验转场、裁切和安全区，不能直接沿用竖屏坐标。可选环境变量 `BIGHEAD_SKILL_PATH` 指向另一个完整的原版技能目录。
3. 依 [Token Plan 旁白](token-plan-narration.md) 生成旁白，并依原项目流程导入旁白与制作字级时间线，编写导演表，准备并核对人物照片、场景、道具，使用 `stage.js`、`acts.js` 与原版视觉制作场景，再进行音效、音乐、字幕、抽帧和成片校验。具体命令见原项目 `SKILL.md` 和 `references/production.md`，运行脚本时以本技能 `vendor/bighead-collage` 为原项目目录。
4. 单独短片默认 9:16、15–60 秒；个人技能横屏讲解中的故事段落使用 16:9 横屏舞台；视觉不是每句话配一张静图。横屏视频包含竖屏故事段落时，需要按横屏重新编排并检查可读性；可以分别渲染故事段和个人图表段，再按时间线合成为一条视频；它是独立的 HTML 舞台渲染能力，不是可以直接放入 Remotion 的现成 React 组件。不得声称已自动完成跨引擎合成。

技能中包含原项目代码和参考资料，不代表已安装运行依赖或开通所有模型服务；按实际情况检查。默认配置和提供商选择以原项目真实配置为准，不预设已有授权或已经下载模型。参考故事不等于真实素材授权。

## 横屏复用与合成

横屏工程的 `a/story-landscape.js` 提供 `STORY_LANDSCAPE.picture(scene, {src,x,y,w,t,fromX,fromY,duration,depth,cutout,show})` 放置人物或道具，以及 `STORY_LANDSCAPE.caption(scene, text, {bottom,size})` 添加不随镜头缩放的字幕；素材、文字、位置、动作、旁白时机和镜头均由制作者根据具体故事设计，不会自动搜索或理解文案。使用时先准备存在且有许可的图像，再按素材语义、画幅、遮挡情况编排。大头、镜头、场景衔接仍按原项目设计，辅助函数不是现成故事模板。

分别渲染故事片段及个人图表片段后，可写合成清单（路径相对清单所在目录）：

```json
{"clips":["story.mp4","chart.mp4"],"audio":[{"file":"voice.wav","start":0.2,"volume":1},{"file":"music.wav","start":0,"volume":0.08}]}
```

运行 `node scripts/assemble-story.mjs <清单.json> <新文件.mp4>`。该工具按顺序拼接画面并混合列出的音轨；不保留输入片段自带音频，不生成配音、字幕或音效，不自动计算口播对齐。各轨音量和起点要根据片子检查；输出为 1280×720 / 24 fps，画幅不同的片段会等比缩放并补黑边。它只做硬切；需要动画转场时应单独设计和渲染。依赖本机 ffmpeg，不覆盖已有目标文件。检查成片音量、字幕安全区、时间对齐及故事与数据衔接。
