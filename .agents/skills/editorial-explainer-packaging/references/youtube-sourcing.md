# YouTube 素材获取

仅在选题确需 YouTube 素材且已确认使用条件时使用。先记录原链接、作者、内容、所需片段、许可或授权与用途；查看平台服务条款和适用规则。官方账号、公开视频、可下载或署名均不自动等于获得剪辑、再发布或商用许可；权限未核实时标为待确认，使用许可清楚的素材作为替代。

## 本机已知路径与检查

Windows 便携程序位于 `C:/Users/DELL/Desktop/yt-dlp/yt-dlp.exe`，同目录的 `yt-dlp.conf` 启用了 Node JS 运行时、视频音频择优和 MKV 合并，并引用了用户本机登录状态文件。此路径和配置仅是该设备曾经的状态，不应假设其他电脑存在。先确认可执行文件、Node、FFmpeg 和输出目录可用；找不到时使用用户指定的可用程序或说明缺口。不要自动安装、更新、覆盖配置或切换账号。

既有记录中带该便携配置的 `--simulate` 成功取得一个视频的标题，并显示使用 Node 解算；**该记录本身不证明完整视频下载、任意视频或当前环境一定成功**。确认来源可用后，可先做只读元信息检查；需要实际素材时，以目标项目目录为输出位置，只处理需要的视频，检查命令的实际退出状态、输出文件、时长、画面与音轨。使用 `ffprobe` 核对封装和流信息，MKV 不应误称为 MP4；需要 MP4 时确认编解码器兼容再单独转换。取得素材与获取使用许可分开记录。

PowerShell 示例（将变量替换为已经确认可使用的视频、可执行程序及项目素材路径；输出目录须事先存在）：

```powershell
$ytdlpExe = 'C:/Users/DELL/Desktop/yt-dlp/yt-dlp.exe'
$videoUrl = '<已核对使用条件的视频链接>'
$outputPattern = 'projects/<项目>/assets/video/%(id)s.%(ext)s'
& $ytdlpExe --no-playlist --simulate --print '%(id)s | %(title)s' $videoUrl
& $ytdlpExe --no-playlist -o $outputPattern $videoUrl
```

示例使用该可执行文件自己的便携配置，配置可能携带登录凭据。使用前先确认该配置适合当前来源和用户授权；不从浏览器或系统中自动读取、导出其他账号凭据。登录状态文件属于敏感凭据：不读取或输出内容、不拷贝进项目、不提交仓库、不发送给外部人员；不要在公开日志、成片或素材台账中记录凭据或可复用的签名链接。调试时避免 `-v` 或输出完整配置；若认证过期或被拒，说明现象并由用户处理其登录状态，不反复尝试、绕开限制或承诺成功。若凭据曾泄露，提醒用户检查并撤销受影响的登录会话。

问题排查：区分网络不可达、认证拒绝、JS 运行时缺失、输出合并失败和格式不支持；根据真实报错采取合规的解决方案，不能把每个 403 都归因于某一个问题。记录作者、来源页面、下载时间、授权状态和实际使用范围；版权或平台条件不明时先标待确认，不能因写有来源就视作已授权。
