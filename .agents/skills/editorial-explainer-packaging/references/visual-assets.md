# 图标与真实素材使用

## 所有图片和人物素材都按内容选择

制作视频时，助理先阅读对应口播和上下文，确定画面主体、群体、动作、时间地点和所需表达，再为每一个使用图片的组件挑选素材并填写路径。逐项覆盖 `people`、`toon`、`icon`、`photo`、`flag`、实体卡徽章、卡片和公式中的图像，以及背景照片、实拍视频等。示例图只是占位，不能因组件原本使用它就默认沿用。组件代码本身只显示传入素材，不会分析口播；这是制作流程中的助理选材规则，不是内置自动识图或素材检索功能。

- `people`：根据口播描述的群体选择合适人物图；`n`、`litn`、`lt` 应反映对应样本总量、点亮数量及时间。原版按 `n` 重复同一张图，不能假装这些重复图片代表真实个体或多样化人群；需要不同人物时须另行设计布局。比例化展示需要说明其简化方式，避免把示意数量当作精确样本。
- `toon`：按所讲角色、身份或场景选择透明 PNG；抽象示意角色可使用贴合内容的插画，真实人物则使用身份和出处可核验且适合使用的素材，不能用无关人物冒充。
- `flag`、实体徽章及其图片：与所讲国家、机构或对象相符；真实名称、标识和时间须核对，不能以近似素材替代后当成真实证据。
- 找不到适合的素材时，先根据任务准备、获取或绘制；对真实身份与事件，不能用生成示意图冒充真实照片。暂时无法验证时保留文字表达或说明素材缺口，不把演示图当作事实。

## 根据内容选图标

1. 先提炼该项内容是什么、观众要理解什么，再选能直接表达它的图形：学习可用书本，练习可用笔记和铅笔，进步可用增长标记；不是所有“积累”都适合用金币。财经可用货币、账本或账户；科技可按芯片、数据、网络等具体对象选择，不把固定一组图标套给所有科技话题。
2. 先查现有 `public/icons/` 是否有合适文件；没有就依据实际话题准备用户提供、授权可用或自行绘制的素材。示例工程有 `icons/editorial-study.svg`、`icons/editorial-practice.svg`、`icons/editorial-progress.svg`；它们仅对应示例概念，不是其他题材的默认图标。
3. 图标含义模糊、可能暗示错误事实或只会增加干扰时，换更贴切的图标或不使用。真实人物、企业和历史事件优先使用与事实相符的素材，不用抽象小图标冒充照片证据。
4. 分镜里显式填写每项素材，按该组件的接口指定；以实际出现的图片为准。检查路径存在、图像未被裁掉、和文字不重叠，并在口播对应内容出现时显示。不要把演示固定图标或默认主题当成自动语义匹配。

常见接口（路径相对工程 `public/`）：

```python
# 基础公式：简写会按 icons/<名称>.png 查找；完整相对路径支持 SVG/PNG。
sc.add('formula', t, x=960, y=520, size=120, items=[
    {'s': '学习', 't': t, 'lab': '获取知识', 'icon': 'icons/editorial-study.svg'},
    {'s': '+', 'op': True, 't': t + .2},
    {'s': '练习', 't': t + .4, 'lab': '运用知识', 'icon': 'icons/editorial-practice.svg'},
])
```

- `formula.items[].icon`：传 `icons/文件名.svg` 等相对路径，或无路径的 PNG 名称；`iconh` 控制高度。需有对应 `lab` 才显示该行图标。
- `formula6.toks[].icon`、`wall.cards[].icon`：传 `icons/文件名.svg` 等完整相对路径；这些组件也有有限的内置 `iconKind`，指定已知内置 kind 时会优先使用它而不是 `icon` 文件。
- `card.icon`、`icon.src` 可用对应组件支持的路径；`people.src` 和 `toon.src` 是原版的 PNG 名称，分别对应 `public/icons/<src>.png` 和 `public/toon/<src>.png`。组件和资源的完整参数以引擎 `COMPONENT_GUIDE.md` 及源代码为准。

## 真实素材

- 照片卡：在个人引擎中 `photo` 接受 `src: 'photos/xxx.jpg'`、`cap` 和 `credit`；将文件放到工程的 `public/photos/`，图片应与讲述的对象及时间相符。
- 整屏图片或实拍：场景 `bg` 使用 `{'type':'broll','img':'broll/xxx.jpg'}` 或 `{'type':'broll','video':'broll/xxx.mp4'}`，文件存放在 `public/broll/`。片段时长、起点及字幕安全区应提前核对；黑色默认底色是普通图形场景的默认，不阻止用户要求的真实素材画面。
- 原技能的 `scripts/commons_photo.py`、`references/research.md` 和 `templates/facts_template.md` 位于本机原技能目录；新工程创建器不会复制它们，需按原目录调用或显式复制所需辅助文件。下载依赖网络与来源可用，不能视为素材已经下载或已授权。
- 按来源和许可记录作者、来源页、许可、必要署名、查阅日期及版本；在需要时将署名放上画面。涉及数字或新闻时依据可靠资料核验事实；把模拟数据、插画和真实证据明确区分。

## 科技题材的边界

按用户要求，个人技能不接入原技能 v1.1 的科技主题或新增组件。科技题材仍可选用贴合内容的素材，使用已确认的个人组件设计。
