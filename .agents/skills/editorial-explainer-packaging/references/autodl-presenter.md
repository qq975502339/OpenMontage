# AutoDL 数字主持人按需生成

> 这是数字主持人的**备用路径**。主持人默认走 Vidu S2 非实时版（见 [Vidu 数字主持人](vidu-presenter.md)）；仅当 Vidu 不可用、积分不足（低于 45 分）、用户明确指定 AutoDL，或需要逐镜约束镜头与人体时才使用本文件。

在个人讲解视频需要数字主持人时，不要求用户上传完整的数字人视频。使用 OpenMontage 工具注册表中的 `autodl_comfyui_video`，显式指定 AutoDL 工作流 `minimax_h3_image_audio_to_video_v2_15s`。先读 `.agents/skills/autodl-comfyui/SKILL.md` 和项目中适用的制作流程；接口以 [AutoDL 工作流页面](https://www.autodl.art/large-model/comfyui/minimax_h3_image_audio_to_video_v2_15s) 为准。此工作流不同于默认的 H3 文生视频工作流。

## 提示词编写：强制步骤

每次编写、调整或重写数字主持人的提示词前，必须先读取当前 OpenMontage 项目 `.agents/skills/h3-prompt-writing/SKILL.md`，并按实际输入模式读取其引用的参考文件；此要求适用于样例、正式生成及重生成。不可仅凭记忆套用通用提示词。

先判定 T2VA、I2VA、FL2VA、L2VA 或 Ref2VA：基础文本／关键帧模式读取 `h3-prompt-writing/references/base-en.txt`，完整图像和音频参考模式读取 `h3-prompt-writing/references/ref-en.txt`。遵循该技能要求的字段、顺序、引用标签和时间格式；描述语言按该技能规定，中文口播原文保持中文。明确人物外观、对应参考图和参考音频、说话内容、时长、镜头，以及下节「口播镜头硬约束」要求写入的全部禁止项。参考素材标签须与实际提供的素材一一对应；不提供的素材不得虚构标签。生成后仍需实际检查口型、声音和颈部运动。

## 口播镜头硬约束

主持人口播片段的提示词里，镜头与人体两部分必须逐条写出下列禁止项，不能只写一句"镜头稳定"：

- **镜头**：禁止推、拉、摇、移、跟、升降、环绕；禁止重新构图、变焦、裁切变化；禁止背景变化（换景、背景元素漂移、明暗跳变、影子移动）；禁止画面抖动、呼吸式起伏、边缘闪动。
- **人体**：脖子、喉咙、下巴、肩膀、衣物和麦克风不得出现皮肤波动、液化、融化、拉伸和几何变形；不得出现颈部肌肉抽动、鼓起、脉动，下巴与脖子粘连，肩膀轮廓塌陷，衣领与布料纹理蠕动，麦克风或耳机弯曲、抖动、漂移、穿模。
- 只允许说话必要范围内的口型、眨眼和极轻微自然呼吸。

生成后必须逐部位检查，任一不合格就重生成，不能靠剪辑掩盖：

| 部位 | 看什么 |
|---|---|
| 脖子 / 喉咙 | 皮肤是否抽动、鼓起、脉动、融化；说话与吞咽时是否撕裂 |
| 下巴 | 与脖子是否粘连；下颌线是否被抹平、拉长、扭曲 |
| 肩膀 | 轮廓是否塌陷、拉伸；左右是否突然不对称 |
| 衣物 | 衣领、布料纹理是否蠕动、扭曲、穿模 |
| 麦克风 / 耳机 | 是否弯曲、抖动、漂移、穿模 |
| 背景 / 构图 | 是否出现推拉摇移、重新构图、背景变化、整体抖动 |

检查方法：按段完整播放一遍，核对口型与台词；用 `ffmpeg -i 片段 -vf fps=6` 抽帧拼接触表逐张看；再比对首帧与末帧的构图、背景和麦克风位置，位置有位移即视为未满足锁定要求。模型输出是概率性的，提示词不是保证，抽帧检查才是验收依据。

## 制作与参数

1. 按文案和分镜选出确实需要主持人的镜头，先确定完整视频计划时长和旁白，再规划镜头。用户没有提供人物视频时，可准备一个原创、可合法使用的主持人参考图以及一条统一的配音；先呈现短样供确认，固定同一形象、服饰和声音。用户提供参考图或音频时先确认其授权与使用范围。不要把生成的主持人误称为真人。
2. 每次调用设置 `duration` 为 5–15 秒的整数、横屏 `resolution: "768p横"`（或按项目画幅选择工作流支持的 480p/768p 横竖选项）。传入具体且与每段台词和时长相符的 `prompt`。通过 `body` 的 `ref_image_0` 和 `ref_audio_0` 等字段传入工作流可访问的参考素材 URL；不要声称本机文件路径可直接被远端读取。必要时使用已授权的素材上传流程，保护隐私与素材权限。该工作流网页列出最多九张图、三段音频；实际字段、权限与服务状态须现场确认。
3. 口型要与实际旁白对齐，提示词必须按上文「口播镜头硬约束」逐条写入镜头与人体禁止项，并要求脸部口型与表情自然。模型输出是概率性的，此提示不是保证；按该节的检查表逐段播放、听音、抽帧检查口型、台词、人物一致性、颈部和画面。存在异常就调整或重生成；无法满足时如实报告，不得假装通过。
4. 完成后把生成片段按时间线组合至华尔街主持人画面或个人组件场景；按实际能力处理背景、抠像、画中画和字幕，单独核对音轨及音画同步。素材导入或转帧可能不保留音频，必须按时间线混合正确的声音。不得声称生成、抠像和同步已自动完成，除非实际执行验证。

## 时长计算

- 数字主持人在最终成片中实际可见的总时长为最终视频总时长的 30%（以一帧为计算精度）。按最终时间线以时间区间的并集计算，全屏、画中画和分屏中可见均计入，重叠时间只算一次；主持人完全被遮挡的时间不算。
- 每次生成的原始片段为 5–15 秒；剪辑时可按语义和节奏裁短、拆用，以使成片可见时间达到 30%（允许最多一帧的舍入误差）。以实际输出帧数和最终成片时长复核比例，记录计算结果；时间线必须避免因切换、转场或画中画重复计时。若时长过短或其他用户约束使比例不能精确实现，说明偏差，不得虚报。
- 该工作流文档允许 1–15 秒，但个人技能按用户要求只提交 5–15 秒。输出实际时长可能与请求时长有细微偏差，剪辑时以探测结果为准。

## 实际验证边界

2026-11-09 已用上述工作流、不提供参考图或音频，生成单段请求 5 秒的虚构人物样例；返回视频约 5.17 秒并带音轨。此结果只证明无参考条件下可提交生成，不证明参考图、参考音频的上传和驱动、精确口型、跨片段身份一致性或颈部完全静止已经端到端验证。正式制作前应实测这些条件；如权限不足、素材无法访问或服务不可用，报告阻碍，不擅自换工作流。
