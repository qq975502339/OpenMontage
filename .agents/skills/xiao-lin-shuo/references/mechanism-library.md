# Mechanism Library

Use this to pick the hidden variable for topic diagnosis or rewrite. Choose one primary mechanism; secondary factors should support it.

## Measurement Lens

Use when a familiar number or chart creates misleading confidence.

Mechanism:
metric selection -> adjustment choice -> comparison changes -> interpretation changes -> audience asks a better question.

Good for: GDP, inflation, unemployment, rankings, valuation multiples, school scores.

## Gatekeeping Burden

Use when a process seems bureaucratic but is actually screening risk.

Mechanism:
weak decentralized screening -> central gatekeeper raises standards -> process becomes document-heavy -> participants optimize for compliance -> quality improves but friction rises.

Good for: IPOs, licensing, immigration, admissions, procurement, platform review.

## Settlement Layer Control

Use when many institutions rush into an infrastructure layer.

Mechanism:
transaction rail becomes trusted -> users and merchants coordinate around it -> operator captures data/fees/reserves -> incumbents face disintermediation -> regulators redefine boundaries.

Good for: stablecoins, payment apps, app stores, logistics networks, identity systems.

## Forced-Position Pressure

Use when leverage, deadlines, or public commitments trap an actor.

Mechanism:
large position -> adverse movement -> exit becomes expensive -> actor doubles down or seeks rule change -> market/regulator reacts -> system learns new limits.

Good for: futures crises, bank runs, short squeezes, startup fundraising crunches.

## Resource Rent Trap

Use when a country or company has valuable resources but weak institutions.

Mechanism:
easy rent -> power concentrates around allocation -> productive diversification weakens -> external shocks hit harder -> informal survival networks expand.

Good for: oil states, mining economies, monopoly platforms, grant-dependent organizations.

## Visibility Pressure

Use when being watched changes behavior.

Mechanism:
visibility rises -> reputational risk rises -> actors choose safer, more performative behavior -> information quality falls -> trust weakens.

Good for: public classes, earnings calls, social media work, office presentations.

## Metric Substitution

Use when a proxy metric replaces the original goal.

Mechanism:
goal is hard to measure -> proxy becomes target -> actors optimize proxy -> proxy decouples from goal -> reform creates a new proxy.

Good for: education, sales KPIs, GDP targets, algorithmic engagement, healthcare throughput.
