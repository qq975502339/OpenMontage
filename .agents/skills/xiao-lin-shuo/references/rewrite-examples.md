# Rewrite Examples

These are original examples for learning the workflow. They are not Xiao Lin source text.

## Example 1: Topic Diagnosis

User topic:

```text
为什么年轻人越来越不爱买房？
```

Weak framing:

```text
房价高、收入低、观念变化、人口下降、政策影响。
```

Xiao Lin style mechanism framing:

```text
核心问题：为什么房子从"人生必选项"变成了"风险资产"？
隐藏变量：预期收益反转。
机制链：房价长期上涨预期 -> 买房像储蓄和投资 -> 家庭愿意加杠杆 -> 收入和人口预期变弱 -> 房价上涨预期动摇 -> 杠杆从机会变成风险 -> 年轻人延迟或退出购买。
```

Revision lesson:

- Do not list causes first.
- Start from the change in asset identity.
- Let income, population, and policy become supporting variables under the hidden variable.

## Example 2: Draft Paragraph Rewrite

Before:

```text
很多公司都在做 AI，因为 AI 可以提高效率，也可以降低成本，还可以改变商业模式，所以 AI 很重要。
```

After:

```text
你会发现，过去公司买软件，买的是一个工具；但现在公司上 AI，买的可能是一种新的成本结构。以前一个流程要靠人一层层传递，速度慢但边界清楚。AI 进来之后，最先改变的不是某个炫酷功能，而是谁来做判断、谁来承担错误、谁能把同样的活复制一万遍。所以 AI 真正让公司兴奋的，不只是效率，而是它把"边际成本"这件事重新压低了。
```

Revision lesson:

- Replace broad benefits with one hidden variable.
- Convert abstract nouns into decisions and constraints.
- Add a before/after contrast.

## Example 3: Review Comment Pattern

For a draft with many facts but no mechanism:

```markdown
一句话诊断：这篇稿子像资料卡，不像解释视频。

最大问题不是信息不够，而是没有告诉观众这些信息之间谁推动了谁。

建议把核心问题改成：为什么 X 明明看起来有优势，却越来越难维持？

隐藏变量可以选：现金流压力。

机制链：
收入放缓 -> 固定成本不降 -> 管理层更看重短期回款 -> 投入长期能力的钱减少 -> 产品体验下降 -> 增长继续放缓。
```
