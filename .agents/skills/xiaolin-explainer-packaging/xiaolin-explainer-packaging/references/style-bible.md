# 小Lin说讲解包装：风格圣经

依据：逐帧拆解 5 期原片（1080P，每 3 秒 1 帧，去掉全屏出镜后剩 435 帧），并按 12fps 帧差统计 1283 个画面切换事件。样本：财富自由（2026-10）、内存暴涨（2026-05）、AI 巨头（2026-07）、美联储（2024-01）、洗钱（2024-10）。

## 1. 底层逻辑：一句话对应一个画面动作

她的讲解画面不是幻灯片，而是"镜头在一个空间里跟着台词走"。规则如下：

- 一个场景跨 2–8 句台词，持续存在，不是一句一页。公式面板最长连续用了 2 分多钟，期间逐项加入、高亮、划掉。
- 台词里每出现一个名词、数字或对比，画面就做一件事：元素入场、当前项亮起、镜头推到它、划掉旧项。时间点对齐到这个词被说出的时刻。
- 镜头几乎每 2–4 秒推或移一次。缓入缓出，停在新焦点上。切换焦点时，上一个元素压暗并虚化。
- 抽象概念一律配实物：育儿配宝宝图标，国家配国旗，机构配 logo 条，报告配原文页。画面上很少出现孤立的一行字。

## 2. 六条硬规则（v6 用过，写进了组件默认值）

| 编号 | 规则 | 违反时的样子 |
|---|---|---|
| R1 | 主体宽 ≥ 画面 60% 或高 ≥ 55%。至少 1/3 的讲解场景里，主体被画面边缘裁切 | 元素小、居中、四周空，像 PPT |
| R2 | 每 2–3 个深色场景之间插 1 个白纸场景（整页文档、白卡图表、白底 UI） | 全片一种暗色，看久了闷 |
| R3 | 白纸整屏配圆形画中画（右下）。面板或公式配左侧竖向圆角矩形。卡片墙和实体卡不放画中画，或放圆形 | 画中画挡住数据 |
| R4 | 一帧最多 2 个标签。英文小字只放在面板标题和卡片名下面 | 每张卡都有黄标签和英文，画面碎 |
| R5 | 正在讲的那一项亮起，其他项压暗并虚化，镜头移过去 | 所有元素一样亮，观众不知道看哪 |
| R6 | 镜头始终近。卡片场景默认缩放 ≥ 1.12，换项时平移，不退回全景 | 镜头停在全景不动 |

## 3. 版式的分类和选择

讲解帧大致分两类，深色和白纸约各占一半（按接触印样目测，未精确统计）：

- 深色：深色背景加 3D 倾斜面板、卡片墙、公式条、实体卡。
- 白纸：整页报告原文、白卡图表、白底 App 界面。

实拍素材加标题字卡、梗图、3D 卡通形象、片名和章节卡穿插其中。

选择方法：

- 数字是这句话的主角 → `bignum`。一个巨大的数字，可以被画面裁切。
- 并列的 2–4 个概念或选项 → `wall`。大卡排成网格，比画面宽，镜头逐张移动。
- 引用报告、法规或新闻 → `docpage`。用原文，逐字荧光笔，镜头跟读。原文必须是真实来源的逐字引用。
- 时间序列或多项比较 → `paper`（col / barh）。白卡斜放在深色背景上。
- 国家、公司或机构 → `ent6`。紫色竖卡，配国旗章和中英文名。
- 公式或因果链 → `formula6`。一条大公式，每项下面配箭头、图标和说明，当前项加高亮框。
- "如果你……会怎样"类测算 → `ui`。白底计算器，逐个填值，结果数字滚动。

## 4. 色板

| 用途 | 色值 |
|---|---|
| 深色底 | 炭黑 `#1b1a20` |
| 边缘几何色块 | 墨青 `#3f8a86`、橄榄 `#8b9a3c`、灰蓝 `#5b6a9e`、蓝圆 `#4a78c8` |
| 道具钞票 | 暗红 `#8a4a52`，带 ¥ 圆章 |
| 面板 | 深紫 `#3a2a55` 到 `#33224f` 渐变；深青 `#1d2b3a` |
| 数据卡 | 深海军蓝 `#141a2e`，细浅金边 `#d9dca0` |
| 数字 | 柠檬渐变 `#fdfee8 → #d9e47e`（`lime`），加柔光晕 |
| 标签 | 柠檬黄底 `#e3ec98`，深色斜体字 |
| 亮卡 | 奶油底加深字；其余卡变暗 |
| 胶片条 | 黑带加粉色圆角方孔 `#ff7b9c`，只在片名和章节卡用 |
| 白纸 | 底色 `#f4f4f1`（`bg.base` 可改），荧光笔黄 `#fff06a`（mark 的 `c` 可改），另有 `box` 框选和 `under` 下划线 |

## 5. 字体

| 角色 | 字体 | 引擎变量 |
|---|---|---|
| 中文标题、字幕 | 优设标题黑（斜切粗黑） | `F.ys` |
| 中文正文、卡片小字 | Noto Sans SC | `F.heavy` |
| 数字 | Bebas / D-DIN Condensed（窄体粗数字，DIN 的开源复刻） | `F.num` `F.din` |
| 英文小字（字距大的圆体） | Quicksand | `F.en` |
| 文档原文 | Noto Serif SC（宋体） | `F.serifsc` |

字幕：底部居中，白色优设标题黑，细黑边。中文每行不超过约 19 字，按标点切分。

## 6. 画中画

- 圆形：直径约 330px，细金边，右下中心约 (1690, 836)。用于白纸整屏和卡片场景。
- 竖向圆角矩形：左侧，屏幕 x 110–560，约 450×740。用于面板、公式和 UI。主体要放在屏幕 x ≥ 600 的区域。
- 出镜回到全屏时，每隔一次推近到 1.13 倍，模拟她的跳切推镜。引擎自动处理。

## 7. 转场（统计结果）

1283 个切换事件里，1102 个是 1–2 帧的硬切，181 个是 ≥ 3 帧的动画过渡（约 14%）。所以默认用硬切，动画过渡只放在这些位置：进出实拍段、章节切换、面板之间换主题。

| 类型 | 时长 | 配音效 | 常见位置 |
|---|---|---|---|
| whip 甩镜 | 0.36s | whip | 场景 → 场景、实拍 → 实拍 |
| zoom 推镜穿越 | 0.5s | whoosh | 出镜 → 场景、片名 → 正文 |
| zoomspin 旋转推镜 | 0.56s | whoosh | 进入章节卡 |
| flash 光斑 | 0.55s | shimmer | 进出实拍、片尾 |
| glitch 故障 | 0.3s | glitch | 实拍 → 出镜、"打脸"反转 |
| push 推移 | 0.45s | swish | 场景 → 出镜 |
| iris 圆形扩散 | 0.55s | swish | 饼图、圆章 |

引擎按相邻两段的类型（出镜 A、场景 S、实拍 B、标题 T、片尾 E）轮换分配，其中约一半是硬切。不要手动给每个切换都加转场。

## 8. 元素运动

- 入场：从下方或侧方滑入，带轻微过冲回弹（`up` `left` `right`）；卡片翻转（`flip` `flipy`）；重击（`slam`）；文档和图表从画外 3D 飞入（`fly3d`，引擎自动分配）。
- 数字滚动计数，约 0.8 秒。
- 荧光笔从左到右刷过，跨行时按行依次刷。
- 手绘圈和下划线做描线动画。
- 场景整体有轻微的 3D 摇摆（`sway`，默认 0.5°）。片名和章节卡设为 0。

## 9. 声音

- 人声 RMS 约 -20 dBFS。音乐在说话时比人声低 12–16 dB，在卡片和停顿处抬高。
- 音效比人声低 20 dB 以上。入场用 whoosh 或 swish，数字用 pop，金额用 kaching，错误用 buzz，荧光笔用 marker，打字用 typing。
- 成片响度 -16 LUFS，真峰值 -1.5 dBTP。

## 10. 不要做的事

- 不要一句一页，也不要让所有元素同时淡入。
- 不要把元素居中缩小到画面一半以下。
- 不要编造报告原文、政策条文或数据。`docpage` 只放能核对来源的逐字引用。
- 不要去掉"AI 生成"标注。
