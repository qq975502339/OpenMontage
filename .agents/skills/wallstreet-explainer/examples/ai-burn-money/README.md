# 示例：《AI到底有多烧钱》（第六版，77 秒）

这是一条片子从想法到成片的记录，用来学“怎么想”。**不要照着它的镜头顺序做新片。** 新片的画面要从新片的文案里现想。

- `script.txt`：最终文案。原声部分不在里面，见下表“反应梗”和“扎克伯格”两行。
- `director.md`：第五版的导演表。注意每一镜的“承接”一列：它接住了上一镜的什么。第六版文案和镜头分段没变，改的是每一镜怎么动，见下表。
- `sample.gif`：第六版整片压成的 GIF（360 宽、6 帧/秒，没有声音）。
- `frames_1fps.jpg`：第六版每秒一帧。
- `moves_v6.jpg`：第六版四个动作的连续帧：
  - 镜头沿新闻桌面滑过去；
  - 黄仁勋从实拍原位挪进巨字中间；
  - 横推换人；
  - 原文倒成桌面、图表立起来。
- `v5b_vs_v6.jpg`：同一时刻，第五版 b 和第六版并排。
- `film_lib.js`：第六版的画面代码，用底座 `film_base.js` 和手法库 `moves.js` 写成，和原版逐帧一致。14 镜里 10 镜用了手法、4 镜全手写，每处手法都写了 why。素材不随仓库给，这份代码只用来读：看手法怎么嵌在手写的画面里，不要照抄镜头。
- `moves_lib.json`：对它跑 `render.mjs --moves` 的结果（每镜用了哪些手法），新片可以用 `--prev` 和它比，免得照着排。
- `CREDITS.md`：全部素材的出处（实拍、抠像、新闻截图、照片、音效）。

## 论证主线

追一笔钱：
1. 四家一年砸 7250 亿；
2. 大头流向芯片和数据中心；
3. 卖芯片的英伟达成了全球市值第一；买算力的 OpenAI 估值高但收入小，到 2030 年还要亏 2780 亿；
4. OpenAI 的钱有一笔来自英伟达，钱在英伟达、OpenAI、甲骨文之间转了一圈；
5. 一年砸进去 7250 亿，收回来的差一大截；
6. 这一截就是赌注，连押注的人自己都知道可能白花。

## 每一段怎么动、为什么（第六版）

| 段 | 画面和镜头 | 为什么 |
|---|---|---|
| 开头 | “烧钱”快闪：关键词钉在中央，周围的出处每 5 帧换一张；最后一张冲过镜头 | 观众的视线有落点，一眼看出“全网都在说”；垫在第一句话下面，不空等 |
| 四家 | 四家的资本开支新闻平铺在一张透视桌面上，念到哪家，镜头沿桌面滑到哪张，念到才亮；“这四家”抬高看全 | 东西早就在，镜头去找它；标题里写着公司名和金额，身份自己说清 |
| 加起来 | 桌面放平、压暗、退成底；7250 亿立在上面，从第一家的 1800 亿滚到 7250 亿（满位数、按十亿取整），说到“七千多亿”停 | “加起来”本身就是累加，滚数在这里是内容，不是装饰 |
| 片名 | 数出来的 7250 亿缩成片名上的眉题；底下的数据中心实拍压暗去色，0.42 秒换一座 | 钉住一个东西、底下换实拍：钱 = 这些楼 |
| 钱花哪了 | 片名退开，7250 亿回到中间当锚，底下还在换实拍；“芯片”“数据中心”两个画框一左一右甩进来，钱的线分过去 | 一个数分成两路；两样东西同时停在屏上 |
| 英伟达 | 芯片画框推满屏 → 黄仁勋台上的实拍 →“市值”那一帧他身后的台换成英伟达的绿，“5.2 | 万亿”在他头两侧长出来，他从原位挪到画面中间 →“全世界最值钱”他正好张开双手，字翻成“全球 | 第一” | 人站在巨字前面：这个人 = 这个数；原片里的动作对上台词 |
| OpenAI | 整组连字带人往左横推走（运动模糊），Altman 带着青色的底推进来；“八千五百二十亿”立在他身后；“收入”时肩旁冒出一张小卡“$360 亿”，身后的大字虚掉 | 横推 = 换一个人说；大字和小卡同框，“才 360 亿”一眼可见 |
| 净烧 | 路透原文整页 → 推近刷黄 →“它还准备”整页往后倒成桌面压暗，白底图表立起来，累计净烧跟着曲线滚到 2780 亿 | 可能被质疑的数先给出处；按年累计是真的累加 |
| 算力 | 图表缩到左边，它身后的桌面换成星门工地的实拍（压暗），8560 亿立在右边 | 底下换成实拍：钱 = 这片工地；两个数并排，不用说出来 |
| 资金循环 | 工地实拍虚掉退成桌面；镜头在 OpenAI 上慢漂 →“英伟达”摇过去找到它 → 钱流到哪跟到哪（CNBC 新闻小卡从“投资”箭头旁弹出又缩回）→“转了一圈”拉回看全、亮点跑一圈 →“回到英伟达手里”推过去、其余压暗 | 同一个世界里换机位，镜头的落点就是正在说的那一家 |
| 反应梗 | “难怪黄仁勋总爱说这句：”→ 从他的圆盘撑开小窗：“买得越多，省得越多” | 先铺垫再放；从盘里撑开，观众知道这是谁 |
| 差一大截 | 回到片名那串实拍上问“AI到底有多烧钱？”→ 低机位的地面上红柱长到 7250 亿 → 摇到矮柱打问号 → 镜头沿着差的那一段往上抬，括号跟着画出来 | 开头的数和片名都回来了；镜头的移动本身在说“差得多” |
| 赌 | 差额那一段亮起；四家的筹码沿地面推上去；“能不能”镜头推到问号 | 首尾呼应：押注的就是开头那四家 |
| 扎克伯格 | “连扎克伯格自己都说：”镜头推到 Meta 那枚筹码 → 推过镜头到他本人，三句原声 | 结尾回到一个判断：他们知道可能白花，还是要砸 |

量出来（`motion_check.py`）：画面完全不动的时间 20%（参考片 15–29%，第五版 b 66%），定住超过 2 秒 0 次，镜头在动的时间 24%（参考片 21–27%）。

## 摔过的跤

| 版本 | 问题 | 改法 |
|---|---|---|
| v1 | 全片 PPT 感：AI 生成的写实背景当墙纸；圆盘一个个弹出来排队、重排；每个数都滚；整张平面一起慢慢往外拉 | 当时把动画全砍成淡入和硬切。回头看：该砍的是元素自己演、每个数都滚、AI 墙纸，不是动本身 |
| v2 | 清楚的实拍上压字 | 当时改成实拍上一律不压字。后来改成只留两种压法：人站在巨字前面、实拍退成底 |
| v3 | 低清百科素材；平面慢推；开头的冷却管道没有信息量 | 换官方高清素材；当时把慢推全删了（后来证明删过头） |
| 冷开小样 | 改成了纪录片冷开，偏离参考风格；四刀航拍看不出是谁家的；交了一个没写完的文件 | 在原版基础上改；画面里要有身份；交付前先验证文件 |
| v4 | 镜头之间不接；素材只停零点几秒；原声没铺垫；结尾日落航拍和内容无关；小字多 | 写导演表，逐镜写承接；加铺垫句；去掉英文小字 |
| v5 小样 | 新闻卡随机乱叠，视线没落点 | 照参考片改成关键词钉在中央的快闪 |
| v5 小样 2 | 旁白前空等 2 秒；紧张乐怪；配音没切静音，节奏时长时短 | 空等缩到 0.3 秒，去掉紧张乐，配音切掉首尾静音 |
| v5 | 配音 1.1 倍听着窘迫；扎克伯格第二句砍掉半个词，第三句前面有数字静音 | 配音改回原速，原声剪口按波形重新定 |
| v5b | 和参考片放在一起看差得很远：三分之二的时间整屏定住；人和图形从不一起动；只有淡入和硬切；没有前后层 | 逐帧量参考片，写出 `motion.md`；第六版用当事人抠像演招牌动作，镜头在 2.5D 舞台里走 |
| v6 制作中 | 横推到 Altman 时前几帧露出了采访者（原片的切点比入点晚）；巨字被人挡住一半；芯片画框底部露出原片烧进去的字 | 抠像前逐帧查切点、跳过；按每帧头肩中心把人钉在两组字中间；抽帧时放大裁掉字幕 |
