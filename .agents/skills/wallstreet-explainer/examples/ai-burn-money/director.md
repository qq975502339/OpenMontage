# 导演表：AI到底有多烧钱（第五版）

- 论点：AI 每年砸进去七千多亿，收回来的差一大截；这笔钱里还有一圈在英伟达手里打转，大家都在赌以后能赚回来。
- 时钟：配音，逐词时间来自 timeline.json（这里的秒数是早期一版配音的，换配音后全片顺延；带 ~ 的是写表时还没配音的句子）
- 风格：wallstreet-explainer（第三版/第四版的圆盘、织物舞台、白底图表、金属片名）
- 贯穿案例：一笔钱：四家砸进去的 7250 亿 → 流向芯片和数据中心 → 英伟达和 OpenAI → 在英伟达、OpenAI、甲骨文之间转一圈 → 回到“收回来的差一大截”
